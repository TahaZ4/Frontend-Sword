My Frontend Shield

 The front-end portion of my KH5041CMD coursework is this project.

 It communicates with a Node.js backend via HTML, CSS, and JavaScript.

 (Features): - {User login and registration} - Session-based authentication - Safe dashboard; - Route display

 (How to operate)
 1. Use port 3000 to launch the backend server.
 2. Use npx serve, for example to serve the frontend files.
 3. Launch the browser and access the frontend.

 Cookies and server-side sessions are used for authentication.
